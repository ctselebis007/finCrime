Setup

Connect to MongoDB Atlas, seed the FinCrime collections with synthetic data, then create the regular indexes and Atlas Search indexes (the MongoDB equivalent of the Elasticsearch mappings).

1 · Connection

Use an Atlas mongodb+srv:// URI (or local Atlas) so Atlas Search indexes can be created.

2 · Create & seed collections

Creates all 10 collections and inserts synthetic, referentially-linked documents. Existing documents are cleared first so this is safe to re-run.

3 · Create indexes

Regular b-tree indexes are created immediately. Atlas Search indexes build asynchronously and require an Atlas cluster (or local Atlas with a search node).
